# Lao David Portfolio

A warm, minimal personal portfolio for Lao David, a Bachelor of Software Engineering student in Phnom Penh focused on Java, Spring Boot, REST APIs, and practical database-driven systems. The site presents confirmed skills, selected projects, education, experience, volunteering, media, and contact information in a responsive, accessible single-page layout.

## Technology stack

- Semantic HTML5
- CSS with shared design tokens and responsive layouts
- Vanilla JavaScript for the accessible mobile menu and current footer year

No frameworks, package installation, or build step are required.

## Current sections

- Sticky navigation and Hero
- About Me and education background
- Grouped technical skills
- CV availability
- Featured projects: Clinix and InvoSight
- Other projects: DSA Java Toolkit, Deepiso, and Nudge
- Reports and certificates with intentional coming-soon states
- Experience and volunteering
- Media section for planned videos
- Contact information
- Footer with quick links and automatic year

## Structure

- `index.html` — accessible page skeleton and primary content sections
- `css/variables.css` — shared design tokens
- `css/base.css` — document-level defaults
- `css/components.css` — reusable component styles
- `css/sections.css` — section-specific styles
- `css/responsive.css` — responsive layout rules
- `js/main.js` — lightweight page behavior
- `assets/` — images, documents, and icons

## Run locally

1. Open this folder in VS Code.
2. Install the **Live Server** extension if it is not already available.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Open the local address shown by Live Server. The configured port may vary by workspace.
